# PlantPlotGAN – Plant Disease Prediction

This repository accompanies the paper  
_**PlantPlotGAN: A Physics-Informed Generative Adversarial Network for Plant Disease Prediction**_,  
presented at **WACV 2024**.

Developed in **2023**, this codebase includes the `PlantPlotGAN` model, which generates synthetic data for agricultural plots to support plant disease prediction tasks. While no major updates are planned, the code remains available for research and educational purposes.

This work was conducted by the repository owner during a postdoctoral position at the **Remote Sensing Lab**,  
**Saint Louis University**.
